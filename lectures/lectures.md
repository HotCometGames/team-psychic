# lectures/

Interactive lecture notebooks for BWSI SGAI 2026. Open in JupyterLab with the `bwsi-sgai` environment active:

```
jupyter lab
```

---

## Files in this folder

| File | What it covers |
|---|---|
| `module_01_game_mechanics.ipynb` | Game loop, humanoids, scoring, and enums (`gameplay/`) |
| `module_02_data.ipynb` | Image dataset, DataParser, and unvisited-humanoid tracking (`data/`) |
| `module_03_ui.ipynb` | Tkinter widgets: buttons, clock, capacity meter, and game viewer (`ui/`) |
| `module_04_architecture.ipynb` | Turn flow, environment interfaces, and main.py wiring (`game_interfaces/`) |
| `module_05_perception.ipynb` | HumanoidClassifier ABC, CNNClassifier, and OracleClassifier (`models/`) |
| `module_06_decision.ipynb` | ActionRecommender ABC, HeuristicRecommender, and RLRecommender (`models/`) |
| `module_07_training.ipynb` | CNN and DQN training loops, hyperparameters, and saved baselines (`training/`) |
| `module_08_tests.ipynb` | Pytest suite structure, test patterns, and coverage across 14 test files (`tests/`) |
| `module_09_ai_exploration.ipynb` | Claude Code capstone: extending the codebase with AI-assisted development |
